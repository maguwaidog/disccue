01 / THE PROBLEM

好きなディスクも、
いつもの再生環境も。

海外版Blu-rayや4K UHD Blu-rayを手に入れても、必要な言語の字幕が収録されていないことがあります。利用する権利のある外部SRTを用意できるなら、DiscCueで字幕の表示系統を追加できます。

映像はいつものBlu-ray／UHDプレーヤー、AVアンプ、TV／プロジェクターから。映画をPCで再生する必要も、字幕のためにプレーヤーを買い替える必要もありません。字幕専用の表示先を映画と同じ視野に配置し、手元のPCでタイミングを合わせます。

Missing your preferred subtitle language on an imported disc? Keep your existing home theater equipment and add a separate subtitle output using an SRT file you are authorized to use.

映画・字幕ファイルは付属しません。

DiscCueは字幕表示・投影のためのソフトです。映像プレーヤーやリッピングツールではありません。映画や著作権で保護された映像を提供、ホスト、ストリーミング、配布せず、SRT等の字幕データも提供しません。合法的に入手した映像と、利用する権利のある字幕をユーザー自身で用意してください。

Users provide their own subtitle files. DiscCue does not provide, host, stream, or distribute movies, copyrighted video content, or subtitle files. Use legally obtained media and subtitle files you are authorized to use.

02 / HOW IT WORKS

ふたつの表示系統。ひとつの視野。

External Subtitle Projection System for Windows Home Theater

映像の経路 Movie path

  1. Blu-ray / UHD Playerいつものディスクプレーヤー
  2. Main Display / Projector映画用のTV／プロジェクター
  3. Movie映画の映像をそのまま表示

字幕の経路 Subtitle path

  1. Windows PC + DiscCueユーザー自身のSRTを読み込む
  2. Subtitle Display / ProjectorPCにつないだ字幕専用の別表示先
  3. SRT Subtitlesスタイル・位置・タイミングを調整して表示

映画と字幕の表示先を、同じ視野に配置します。

映像へのデジタル合成は行いません。DiscCueは映像信号を加工せず、既存の再生機器も変更しません。字幕の同期は手動で操作します。
Separate physical outputs in one viewing field. DiscCue does not alter or digitally composite into the video signal. Subtitle synchronization is manual.

07 / FAQ

よくある質問

DiscCueとは？

自分のSRTを別ディスプレイ／プロジェクターへ表示し、映画に合わせて手動で同期するWindowsアプリです。映画と同じ視野へ字幕を配置するホームシアター用の字幕表示・投影ツールです。

映画や字幕ファイルは付属しますか？

付属しません。映画・映像・字幕の提供、ホスト、ストリーミング、配布は行いません。合法的に入手した映像と、利用する権利のある字幕を自身で用意してください。リッピングを行うソフトでもありません。

自分のSRTを使えますか？

はい。ローカルのSRTファイルを読み込みます。字幕のダウンロード、クラウド検索、翻訳サービスは含まれません。

Blu-ray／UHDプレーヤーを買い替える必要がありますか？

いいえ。映画は既存のプレーヤーで再生します。Windows PCに字幕専用の別ディスプレイ／プロジェクターをつなぎ、映画と同じ視野へ配置してください。

映画をPCで再生する必要がありますか？

ありません。DiscCueが扱うのは字幕側だけです。映画の映像信号は加工せず、映像へのデジタル合成も行いません。

FREE Trialはどのように30分を数えますか？

投影画面を開いて字幕再生が進んでいる時間を累積で数えます。SRT読み込み・表示設定・一時停止・停止中は消費しません。アプリを再起動しても残り時間を引き継ぎ、30分を使い切ると投影再生が一時停止します。Current Line SyncはStandardの機能です。

Standardはいくらですか？

¥2,480の買い切りです。投影再生時間の制限を解除し、Current Line Syncを利用できます。現在このサイトでは購入リンクを提供していません。

サブスクリプションですか？

いいえ。Standardは一度購入する方式で、定期課金はありません。

何台まで使えますか？

1ライセンスで最大2台まで認証できます。別のPCへ移すときは、現在のPCでインターネットに接続して認証解除し、利用枠を戻してから新しいPCで認証してください。

オフラインで使えますか？

はい。Standardは初回のオンライン認証後、通常の字幕利用をオフラインで行えます。定期的なオンライン再認証は要求しません。認証解除にはインターネットが必要です。

字幕のタイミングがずれた場合は？

再生・一時停止、オフセット、Seek／Jumpで手動調整します。StandardのCurrent Line Syncは、表示中の字幕行を字幕再生時計に合わせてオフセットを補正します。映画や音声を検出して自動同期する機能ではなく、元のSRTも書き換えません。

対応OSは？

Windows版です。Windows 11を設計対象とし、確認済みインストーラーはx64 MSIです。正式な対応OS一覧・最小バージョンは配布開始時に掲載します。購入前にはFREE Trialで自分の表示機器を含めて確認してください。

mmd.apps303@gmail.comへご連絡ください。Windowsのバージョン、アプリのバージョン、表示機器、発生した問題を添えると確認しやすくなります。ライセンスキーや映画・字幕ファイルは送らないでください。
