01 / THE PROBLEM

好きなディスクも、
いつもの再生環境も。

見たい作品に国内版の4K UHDがなく、海外盤を選ぶことがあります。しかし、必要な日本語字幕が収録されているとは限りません。DiscCueは、オリジナルのディスクといつもの再生機器を使い続けながら、自分で用意した字幕だけを別系統から同じスクリーンへ投影したい、という使い方から生まれました。

映画は通常のBlu-ray／UHDプレーヤーから映画用プロジェクターへ。Windows PCのDiscCueから字幕用プロジェクターへ。字幕の位置とタイミングを合わせて、同じスクリーンで視聴します。

Keep using your original disc and usual player. A second projector, connected to a Windows PC running DiscCue, places your SRT subtitles on the same projection screen. Subtitle timing is manual.

02 / HOW IT WORKS

2台のプロジェクター、1枚のスクリーン。

  1. 映画はいつもの機器で再生。

    Blu-ray／UHDプレーヤーから、映画用プロジェクターでスクリーンへ投影します。

  2. 自分のSRTをDiscCueで開く。

    Windows PCでSRT字幕を読み込みます。

  3. 字幕用プロジェクターへ出力。

    PCに接続した字幕用プロジェクターを表示先に選び、字幕専用出力を開きます。

  4. 同じスクリーンへ字幕を配置。

    字幕用プロジェクターを同じスクリーンへ向け、字幕の位置とタイミングを手動で合わせます。

映画と字幕の再生は独立しています。映画を一時停止・Seekしたときは、字幕側も手動で操作してください。

07 / FAQ

よくある質問

別モニターを見ながら字幕を読む必要がありますか？

主な利用構成では必要ありません。映画用プロジェクターで映画を投影し、Windows PCにつないだ字幕用プロジェクターで字幕だけを同じスクリーンへ投影します。別モニターで字幕を表示する使い方も選べますが、それは副用途です。

TVで再生している映画へ直接字幕を重ねられますか？

現在は対応していません。DiscCueは映画のHDMI信号を取得・加工せず、字幕を直接挿入しません。同じスクリーンで見る主な利用構成は、映画用と字幕用の2台のプロジェクターです。

DiscCueとは？

自分のSRT字幕を読み込み、字幕用プロジェクターへ出力するWindowsアプリです。主な利用構成では、映画用と字幕用の2台のプロジェクターで映画と字幕を同じスクリーンへ投影します。字幕の表示・位置・再生・タイミングをDiscCueで手動操作します。DiscCueは映画を再生せず、映画のHDMI信号を取得・加工しません。

映画や字幕ファイルは付属しますか？

付属しません。映画・映像・字幕の提供、ホスト、ストリーミング、配布は行いません。合法的に入手した映像と、利用する権利のある字幕を自身で用意してください。リッピングを行うソフトでもありません。

自分のSRTを使えますか？

はい。ローカルのSRTファイルを読み込みます。字幕のダウンロード、クラウド検索、翻訳サービスは含まれません。

Blu-ray／UHDプレーヤーを買い替える必要がありますか？

いいえ。映画は既存のプレーヤーから映画用プロジェクターへ送ります。Windows PCにつないだ字幕用プロジェクターを、映画と同じスクリーンへ向けてください。

映画をPCで再生する必要がありますか？

ありません。DiscCueが扱うのは字幕側だけです。映画の映像信号は加工せず、映像へのデジタル合成も行いません。

FREE Trialはどのように30分を数えますか？

投影画面を開いて字幕再生が進んでいる時間を累積で数えます。SRT読み込み・表示設定・一時停止・停止中は消費しません。アプリを再起動しても残り時間を引き継ぎ、30分を使い切ると投影再生が一時停止します。Current Line SyncはStandardの機能です。

Standardはいくらですか？

日本向け¥2,480（税込）の買い切りです。投影再生時間の制限を解除し、Current Line Syncを利用できます。同じDiscCueアプリにライセンスを認証します。購入はBuy StandardからPolarへ進めます。購入完了後に自動発行されたキーを、注文確認メールの案内からCustomer Portalで確認できます。支払い・提供・返金の詳細もご確認ください。

サブスクリプションですか？

いいえ。Standardは一度購入する方式で、定期課金はありません。

何台まで使えますか？

1ライセンスで最大2台まで認証できます。別のPCへ移すときは、現在のPCでインターネットに接続して認証解除し、利用枠を戻してから新しいPCで認証してください。

オフラインで使えますか？

はい。Standardは初回のオンライン認証後、通常の字幕利用をオフラインで行えます。定期的なオンライン再認証は要求しません。認証解除にはインターネットが必要です。

字幕のタイミングがずれた場合は？

再生・一時停止、オフセット、Seek／Jumpで手動調整します。StandardのCurrent Line Syncは、表示中の字幕行を字幕再生時計に合わせてオフセットを補正します。映画や音声を検出して自動同期する機能ではなく、元のSRTも書き換えません。映画の一時停止・Seekには自動追従しないため、字幕側も手動で操作してください。

対応OSは？

Windows 11 x64で動作確認済みです。Java実行環境を同梱するため、別途JDKのインストールは不要です。購入前にはFREE Trialで自分の表示機器を含めて確認してください。

サポートへの連絡方法は？

mmd.apps303@gmail.comへご連絡ください。Windowsのバージョン、アプリのバージョン、表示機器、発生した問題を添えると確認しやすくなります。ライセンスキーや映画・字幕ファイルは送らないでください。
